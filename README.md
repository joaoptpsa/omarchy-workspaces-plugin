# omarchy-workspaces-plugin

An Omarchy bar widget that shows workspace number indicators. It started as a clone of Omarchy's
built-in `omarchy.workspaces` widget.

## Install

```bash
omarchy plugin add https://github.com/joaoptpsa/omarchy-workspaces-plugin.git --enable
```

Update it with `omarchy plugin update joaosa.workspaces`.
